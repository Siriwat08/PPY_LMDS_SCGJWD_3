## คอลัมน์สำคัญกับสเปกง่าย (หัวใจ)

### กุญแจ 3 ช่อง → `MATCH_KEY`

```text
MATCH_KEY = makeKey(ชื่อ, ที่อยู่, เจ้าของ)
          = cleanName(ชื่อ) + "|" + cleanAddr(ที่อยู่) + "|" + cleanOwner(เจ้าของ)
```

| บทบาทในสเปก | บน SOURCE (ดิบ) | บน ตารางงานประจำวัน (API) | บน MASTER_PLACE (ฐาน) |
|-------------|-----------------|---------------------------|------------------------|
| ชื่อปลายทาง | **ชื่อปลายทาง** | **ShipToName** | เก็บเป็น `NAME_CLEAN` |
| ที่อยู่ปลายทาง | **ที่อยู่ปลายทาง** | **ShipToAddress** | เก็บเป็น `ADDR_CLEAN` |
| ชื่อเจ้าของสินค้า | **ชื่อเจ้าของสินค้า** | **SoldToName** | เก็บเป็น `OWNER_CLEAN` |
| พิกัดจุดส่ง | **LAT**, **LONG** | ผลลัพธ์ที่แปะ = **LatLong_Actual** | **LAT**, **LNG** |
| คีย์รวม | **MATCH_KEY** (helper หลังปุ่ม 1) | **MATCH_KEY** (ตอนโหลด SCG) | **MATCH_KEY** |
| ลิงก์ฐาน | **MD_LINK** | **MD_ID** | **MD_ID** |

## วิธีวางโค้ด

1. เปิด Google Sheet งานจริง → **ส่วนขยาย → Apps Script**
2. ลบ/แทนที่ไฟล์ `.gs` เดิมให้ตรงชื่อกับในโฟลเดอร์ `1_โค้ดหลัก_...`
3. คัดลอกเนื้อหาทีละไฟล์วางทับ (ชื่อไฟล์ใน GAS ควรตรงกัน)
4. บันทึก → รีเฟรชชีต → เมนู Phaopanya ควรโผล่

**คำเตือน:** อย่าเปลี่ยนสูตร `cleanThai` / `makeKey` มั่วโดยไม่มีแผนย้ายคีย์ทั้งฐาน

## วิธีใช้ตามสเปกง่าย (ลำดับประจำวัน)

1. มีข้อมูลดิบบนชีต **SCGนครหลวงJWDภูมิภาค** ที่มีพิกัด LAT/LONG → กด **ปุ่ม 1** (สะสม **MASTER_PLACE**)
2. โหลดงานจาก SCG API ลง **ตารางงานประจำวัน** (ได้ MATCH_KEY ติดมา)
3. กด **ปุ่ม 2** → ดูคอลัมน์ **LatLong_Actual** + **LatLong_Actual_Status** (`FOUND` / `REVIEW`)
4. (ทางเลือก) Self-Test เมื่อต้องการตรวจสุขภาพระบบ
5. (ทางเลือก) ปุ่ม 3/3b เมื่อต้องการคอลัมน์ราชการ U–AA — **ไม่บังคับ** ต่อพิกัดส่งของ

### นิยามสำเร็จ

- ข้อมูลดิบชุดใหม่ → รวม 3 อย่าง → ซ้ำไม่เบิ้ลแถว MASTER / ไม่ซ้ำเข้าฐาน
- API/งานวัน → รวม 3 อย่างชุดเดียว → เจอในฐาน → มีจุดส่งถูกใส่กลับ
- รันซ้ำไม่สร้างขยะแถวซ้ำคีย์
